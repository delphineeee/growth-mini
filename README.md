# Growth Mini

> 从真实岗位要求到7天可验证作品：一个证据驱动的职业成长冲刺工具。

Growth Mini 不预测录用概率，也不使用来源不明的“能力百分比”。它从仓库中的真实 JD 样本提取岗位要求，保留来源证据，再与用户提交的作品证据进行透明比较。

## 当前闭环

1. 读取并分类 JD 样本。
2. 建立“能力—频率—要求类型—来源摘录”矩阵。
3. 用户标记个人能力证据：已有作品、只有自述、暂无证据。
4. 使用确定性公式排序：`岗位权重 × 证据缺口 × 100`。
5. 针对一个最高优先级缺口生成7天作品冲刺。
6. 记录实际耗时、完成情况和产物链接，生成结项证据报告。

## 证据定义

- **已有可验证作品**：GitHub仓库、在线Demo、测试报告、公开PR或完整技术文档。
- **只有自述**：上过课程、阅读过资料、做过笔记，但缺少别人可检查的成果。
- **暂无证据**：当前没有能够支持该能力的材料。

## 评分方法

岗位权重按当前样本计算：任职要求为1.0、岗位职责为0.8、加分项为0.6。证据缺口中，已有作品为0、只有自述为0.55、暂无证据为1.0。

该分数只表示当前样本下的补强优先级，不代表个人价值或录用概率。

## 本地运行

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

打开 <http://127.0.0.1:8000>。

## 测试

```bash
pytest -q
```

## 数据说明

`data/raw_jds/` 保存用户人工收集的岗位资料。每条结果都保留来源文件和不超过140字的证据摘录。当前样本规模较小，任何统计只描述当前数据集。

## 技术栈

- FastAPI + Pydantic
- 原生 HTML/CSS/JavaScript
- 确定性规则抽取与评分
- 浏览器 localStorage 保存个人证据和回访信息
