# Growth Mini

> 从真实岗位要求到7天学习证据档案：一个轻量、可追溯的成长冲刺工具。

Growth Mini 不预测录用概率，也不使用来源不明的“能力百分比”。它从仓库中的真实 JD 样本提取岗位要求，保留来源证据，再与用户提交的作品证据进行透明比较。

## 当前闭环

1. 读取并分类 JD 样本。
2. 建立“能力—频率—要求类型—来源摘录”矩阵。
3. 用户标记个人能力证据：已有作品、只有自述、暂无证据。
4. 使用确定性公式排序：`岗位权重 × 证据缺口 × 100`。
5. 针对一个最高优先级缺口生成7天作品冲刺。
6. 每天记录实际耗时、Markdown 笔记、阻塞、明日第一步和产物链接。
7. 下载一份完整的 Markdown 结项学习档案。

Growth Mini 只汇总用户实际留下的学习记录和产物，不根据完成天数判断“掌握程度”。当前冲刺与每日记录保存在浏览器 `localStorage` 中，刷新或重新打开页面后可以继续；清理浏览器数据、切换浏览器或设备会丢失记录，建议在结项后下载 Markdown 备份。

## 证据定义

- **已有可验证作品**：GitHub仓库、在线Demo、测试报告、公开PR或完整技术文档。
- **只有自述**：上过课程、阅读过资料、做过笔记，但缺少别人可检查的成果。
- **暂无证据**：当前没有能够支持该能力的材料。

## 评分方法

岗位权重按当前样本计算：任职要求为1.0、岗位职责为0.8、加分项为0.6。证据缺口中，已有作品为0、只有自述为0.55、暂无证据为1.0。

该分数只表示当前样本下的补强优先级，不代表个人价值或录用概率。

## 本地运行

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

打开 <http://127.0.0.1:8000>。

## 测试

```bash
pytest -q
```

## 数据说明

`data/raw_jds/` 保存用户从公司官网人工收集的岗位资料。当前样本没有保留原始页面链接，因此界面会明确标注“公司官网（人工摘录，链接未保留）”，并保留公司、岗位、收集月份、来源文件和不超过140字的证据摘录。它适合第一版内部验证，但不能冒充可由外部链接复核的数据集。

## 技术栈

- FastAPI + Pydantic
- 原生 HTML/CSS/JavaScript
- 确定性规则抽取与评分
- 浏览器 localStorage 保存个人证据和回访信息
